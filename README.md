# Долголетие — концепция редизайна

Адаптивный прототип главной страницы медицинской клиники. HTML/CSS/JS без сборки.

## Просмотр
Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

## Статус
Это **неофициальный дизайн-прототип**, не действующий сайт клиники. Визуальные элементы условные; фотографии, специализации врачей, юридическая информация, адрес и контакты требуют подтверждения. Кнопки записи пока ведут на действующий сайт, интеграции нет. Карточки услуг временно ведут на главную действующего сайта до сверки точных URL.

## Дальше
Сверить весь контент с исходным сайтом, получить реальные изображения и согласовать сценарий записи, затем реализовать страницы услуг и специалистов.
